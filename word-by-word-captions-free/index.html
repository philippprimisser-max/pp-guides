Word-by-word captions for free: Whisper + ffmpeg, Premiere Pro and DaVinci Resolve

Word-by-word captions (each word appears or lights up as it is spoken) are standard on Shorts, Reels and TikTok. Web tools work, but often limit clip length, add a watermark or charge monthly. The underlying trick is simple: you need word-level timestamps, and then a subtitle file that shows one word (or a few words) per cue.

Option A: local, free, any length (Whisper)

pip install -U openai-whisper   # needs ffmpeg installed
whisper clip.mp4 --model small --word_timestamps True \
  --max_words_per_line 1 --output_format srt

This writes clip.srt with one word per cue. Use --max_words_per_line 3 for short groups, or --highlight_words True to underline the current word inside a longer line. Use a larger model (medium) if names are misspelled.

Burn it into the video with ffmpeg:

ffmpeg -i clip.mp4 -vf "subtitles=clip.srt:force_style='Fontsize=22,Alignment=2,MarginV=60'" -c:a copy out.mp4

Option B: import into your editor

  • Premiere Pro: File → Import the .srt → drag to the timeline as a caption track; style it in Essential Graphics. Premiere's own Speech to Text can also split captions, but not one word at a time with highlighting.
  • DaVinci Resolve: right-click the .srt in the media pool → Import Subtitle, drag onto the timeline. (Resolve Studio has built-in auto captions; the free version does not.)
  • CapCut: Text → Local captions → import .srt.

Option C: no install

If you don't want to run Whisper yourself, the Podcast Transcriber on Apify returns SRT/VTT with word timestamps and a configurable number of words per cue from a media URL (pay per audio minute; Apify's free plan credit covers testing).

Tips

  • Keep 1–3 words per cue for vertical video, place captions above the bottom UI area.
  • Always proofread names and numbers; speech recognition gets them wrong most often.
