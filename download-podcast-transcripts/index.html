How to download podcast transcripts from RSS feeds (and search them)

A growing number of podcasts ship an official transcript with each episode. It is linked in the RSS feed, so you can download it without any speech recognition.

Check a feed by hand

  1. Find the RSS feed (on the show's site, or search the show on a podcast index such as podcastindex.org).
  2. Open it in the browser and search for podcast:transcript.
  3. The url attribute points to the file; type tells you the format: text/vtt, application/x-subrip (SRT), application/json or text/html.

Command line, latest episode:

curl -s FEED_URL | grep -o '<podcast:transcript[^>]*>' | head -1

In bulk or on a schedule

The Podcast Transcript Fetcher reads one or many feeds (or an Apple Podcasts search), downloads every available publisher transcript, converts it to clean text with timestamps, and can filter by keyword or return only new episodes. Episodes without a transcript are free; they can optionally be handed to the Podcast Transcriber.

Searching transcripts

Once you have text files, plain grep -ril "keyword" transcripts/ already works. For monitoring a topic across many shows, run the fetcher daily with a keyword filter and only-new mode.
