3 things I automate with Apify's free plan (no own scraper needed)

Apify is a platform for running ready-made web automation tools ("Actors") in the cloud. You don't have to write or host a scraper yourself: pick an Actor from the Apify Store, give it input, and get the results as JSON, CSV or Excel.

What the free plan includes

  • $0 per month, no credit card required.
  • $5 of platform usage per month. Unused credit does not roll over; when it runs out, runs are blocked until the next cycle (no surprise bill on the free plan).
  • Most Store Actors charge per result or event (price shown on each Actor page); others bill compute at $0.20 per compute unit (1 GB RAM for 1 hour).

Prices as listed on apify.com/pricing in November 2026; check the page before you rely on them.

1. Turn a website into clean text for notes or an AI assistant

Apify's own Website Content Crawler crawls a site or docs section and returns the main text of each page as Markdown, without menus and footers. Useful for building a searchable archive of documentation you read often.

2. Watch a page for changes

Run a crawler on a schedule (Apify has built-in schedules) and compare the output with the previous run. Good for price pages, job boards or changelogs you would otherwise check by hand. Keep the page count small so a weekly run stays well inside the free credit.

3. Collect search or listing results into a spreadsheet

Many Store Actors return structured lists (search results, listings, reviews). Export the dataset as CSV and open it in Google Sheets or Excel. Check each Actor's per-result price first; on the free plan, a few hundred results are usually affordable.

Run it from Python

pip install apify-client

from apify_client import ApifyClient
client = ApifyClient("YOUR_APIFY_TOKEN")  # Console → Settings → API & Integrations
run = client.actor("apify/website-content-crawler").call(
    run_input={"startUrls": [{"url": "https://docs.example.com/"}], "maxCrawlPages": 20})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["url"], len(item.get("text", "")))

Keep the token out of your code repository (use an environment variable).
