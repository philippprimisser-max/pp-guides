How to search EU tenders on TED and get alerts for new notices

All EU public contracts above the EU thresholds are published on TED (ted.europa.eu), the online version of the Supplement to the Official Journal. Thousands of notices appear every working day.

Search on TED

  1. Use Advanced search: filter by country of the buyer, notice type (contract notice = open tender), publication date and CPV code (the EU's procurement vocabulary; e.g. 72000000 = IT services).
  2. Find the right CPV codes by searching the CPV list for your service, and include parent codes.
  3. Open a notice: deadline, buyer, lots and the link to the tender documents (often on a national e-procurement platform).

Alerts

TED can save searches and send notifications if you log in with an EU Login account. TED also offers a public search API for developers.

Automatic Excel/CSV list

The EU Tender Monitor on Apify queries TED by country, CPV code and keywords, returns each notice with a short summary, deadline and links, and on a schedule delivers only notices you haven't seen, as CSV/Excel. Billed per delivered notice.

Tips

  • Below EU thresholds, tenders are only on national portals; check those too.
  • Read the deadline in the buyer's time zone and leave time for questions to the buyer.
